# Vikash Jaiswal — Academic & Teaching Portfolio

An interactive, modern, and colourful academic portfolio built for **Vikash Jaiswal**, Aspiring Mathematics Educator & BSc BEd student at **IIT Jodhpur**.

---

## 🎨 Theme & Design
- **Theme**: Light & Colourful
- **Accents**: Soft Purple (`#8b5cf6`), Mint Green (`#10b981`), Warm Orange (`#f97316`), Sky Blue (`#0284c7`)
- **Navigation**: Sticky top navigation with smooth scrolling
- **Responsive**: Fully optimized for mobile, tablet, and desktop

---

## 📑 Portfolio Sections
1. **Home (Hero)**: Profile illustration, rotating headlines (*Aspiring Mathematics Educator*, *BSc BEd Student at IIT Jodhpur*, *Educational Tech Enthusiast*), tagline, and quick action buttons.
2. **About Me**: Narrative background, teaching vision, and personal/academic data (IIT Jodhpur, Prayagraj school, email).
3. **Skills**: 10 competencies categorized with visual progress meters and pedagogical badges.
4. **Academic Journey (Education)**: Timeline detailing BSc BEd at IIT Jodhpur and secondary education at Rani Revati Devi SVNIC.
5. **Academic Projects**: Showcase of 5 core projects with tags and descriptions:
   - *Treasure Hunt using Scratch* (Computational Thinking)
   - *Universal Inquiry Board* (Teaching-Learning Resource)
   - *Average Speed Animation* (Mathematics Education)
   - *Interactive Edpuzzle Video* (Digital Learning)
   - *Magnus Effect Teaching Activity* (Physics Education)
6. **Teaching Philosophy**: 4 foundational pillars (Conceptual clarity, Active & hands-on, Technology integration, Inquiry & curiosity).
7. **TLR Gallery**: Exhibition cards of Teaching-Learning Resources and educational media.
8. **Contact & Connect**: Direct academic email (`b24edm014@iitj.ac.in`), social links (LinkedIn, Instagram), and message form.

## 🚀 How to Preview & Run
Double-click `index.html` or open it in any modern web browser.
Alternatively, run a local development server using Python:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

---

## 📌 Pending Customizations & Placeholders
When you have the final files ready, simply replace the placeholders:
- **Profile Photo**: Replace `assets/img/vikash-avatar.svg` with your photo (e.g. `assets/img/vikash.jpg`) and update the `src` attribute in `index.html`.
- **CV / Resume**: Place your PDF file in the root or assets folder and link it in the `Download CV` button.
- **GitHub Profile**: Update the `#` placeholder in the hero and footer with your GitHub URL.
- **Project Screenshots**: Replace the SVG placeholders in `assets/img/project-*.svg` with your actual screenshots.
